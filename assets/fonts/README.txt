Copy your font files into this folder (they are loaded automatically at startup):

  Inter  : Inter-Regular.ttf, Inter-Medium.ttf, Inter-SemiBold.ttf, Inter-Bold.ttf
           (or the single variable font file Inter-VariableFont*.ttf)
  Urdu   : JameelNooriNastaleeq.ttf

Check the license of each font before shipping it inside the installer.
